# Zaveit

A personal bookmark manager: people share links from other apps, and each link is saved with a title, a picture and tags so it can be found later.

## Language

**Post**:
A saved link, together with its title, thumbnail, author and tags.
_Avoid_: Bookmark (as a noun), link, item

**Bookmark**:
The act of saving a Post. A verb only: you bookmark a Post.
_Avoid_: Using "bookmark" for the thing saved

**Main Tag**:
A Tag from the fixed list that every user shares.
_Avoid_: Category, default tag

**Additional Tag**:
Any Tag that is not a Main Tag, including ones a user created.
_Avoid_: Custom tag, local tag

**Suggested Tag**:
A Tag proposed by the AI model for a Post, which the user can keep or discard before the Post is bookmarked.
_Avoid_: AI tag, generated tag
